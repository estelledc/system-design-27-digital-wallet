# Repository instructions

- This is an independent clean-room learning repository for one bounded internal-wallet conservation invariant.
- Keep request accepted, transfer intent prepared, ledger transaction posted, materialized balances changed, statement published,
  reversal posted, real funds moved, and external acceptance as separate facts.
- Never add real wallet/account/customer/payment data, credentials, provider endpoints, internal topology, or copied third-party
  prose, diagrams, fixtures, benchmarks, or code.
- Preserve unrelated work. Stage exact paths, keep commits single-purpose, and do not add co-author trailers unless requested.
- Correctness conclusions require real database/process boundaries in public CI; mocks cannot prove concurrency, balance
  conservation, immutable journal effects, account-generation fencing, response-loss recovery, or stable statements.
- A benchmark is a bounded synthetic observation for its exact fixture and runtime, never money throughput, latency, availability,
  durability, accounting approval, compliance, production capacity, or external acceptance.
